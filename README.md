เขียนโน้ตไทยแล้วกดฟัง ทำงานบนเบราว์เซอร์ล้วน ไม่มี build ไม่มี dependency
เปิดไฟล์ `.html` ตรง ๆ จากเครื่องก็ใช้ได้

## การเขียนโน้ต

```
ดรมฟ ซลทดํ รํมํฟํซํ ลํทํ-- ทํลํซํฟํ มํรํดํท ลซฟม รด--
```

| สัญลักษณ์ | ความหมาย |
|---|---|
| `ด ร ม ฟ ซ ล ท` | ตัวโน้ต (พิมพ์ `d r m f s l t` ก็ได้) |
| `ดํ` | นิคหิตข้างบน = สูงขึ้น 1 คู่แปด (ใส่ซ้ำได้) |
| `ดฺ` | พินทุข้างล่าง = ต่ำลง 1 คู่แปด |
| `-` | ยืดเสียงตัวก่อนหน้า |
| `0` | หยุดเสียง |
| เว้นวรรค หรือ `\|` | ขึ้นห้องใหม่ |
| ขึ้นบรรทัด | บรรทัดถัดไป |
| `//` `#` | คำอธิบาย ไม่ถูกเล่น |
| `"` ต้นบรรทัด | เนื้อร้องของบรรทัดโน้ตข้างบน คำละห้องตามเว้นวรรค `-` = ห้องที่ไม่มีเนื้อ ใส่หลายบรรทัดได้ |

ตัวอักษรที่เขียนติดกันคือ **1 ห้อง** — `ดรมฟ` คือห้องที่มี 4 ช่อง
1 ห้องกินเวลาเท่ากันเสมอ ใส่ 2 หรือ 4 ตัวก็ได้ ระบบแบ่งเวลาให้เอง

**เฉพาะหน้าขลุ่ย**

| สัญลักษณ์ | ความหมาย |
|---|---|
| `(ดรม)` | ลูกสะบัด — โน้ตในวงเล็บซอยเวลากันเองอยู่ในช่องเดียว |
| `ซ*` | เสียงควง — ความถี่เดิม แต่จับอีกแบบ เสียงทึบกว่า |

## สิ่งที่ทำได้

**เสียงและคีย์**
- **เสียงเท่า 7 เสียง** ขั้นละ 171.43 เซนต์ ตามระบบเสียงดนตรีไทย หรือสลับเป็น 12-TET เทียบเปียโนได้
- **ทาง** 7 ทาง (เพียงออล่าง ใน กลาง เพียงออบน นอก กลางแหบ ชวา) และ **คีย์สากล** 12 คีย์
  — เป็นคนละเรื่องกับระบบเสียง จะเลือกคีย์สากลแต่ยังใช้เสียงเท่า 7 เสียงก็ได้
- เลือกช่วงเสียงและตั้งความถี่อ้างอิงเองได้ แสดงโน้ตสากลกับค่าเพี้ยนเป็นเซนต์ให้ดู
- **ฉิ่ง–ฉับ** ตามอัตราจังหวะ ชั้นเดียว / สองชั้น / สามชั้น (เสียงอัดจริง)

**การเล่น**
- ปรับ**ทุกค่าได้ระหว่างเล่น** มีผลภายในราว ¼ วินาที — ตัวตั้งคิวมองล่วงหน้าและอ่านค่าใหม่ทุก 40 ms
- คลิกช่องโน้ตเพื่อตั้ง**จุดเริ่มเล่น** เปิดเล่นวนจะวนกลับมาที่จุดนั้น
- **พัก / เล่นต่อ** จากช่องที่ค้างไว้ · เว้นวรรคบนคีย์บอร์ด = เล่น/พัก
- ไฮไลต์ช่องที่กำลังเล่น จอเลื่อนตามให้ หยุดตามเมื่อกำลังพิมพ์หรือเพิ่งเลื่อนเอง

**การแก้โน้ต**
- **จัดระเบียบโน้ต** — จัดห้องใหม่ตามจำนวนที่ตั้ง ขยายห้องให้ครบ 4 ช่องโดยเสียงไม่เปลี่ยน คำอธิบายตามไปด้วย
- **ขยับคีย์ของโน้ต** — เขียนโน้ตใหม่ทั้งเพลงขึ้น/ลงทีละขั้น ข้ามคู่แปดให้เอง การจัดวางคงเดิม
- **เนื้อร้อง** — แสดงใต้ห้อง ห้องที่กำลังเล่นเป็นสีทอง จัดระเบียบแล้วเนื้อตามห้องไป ขยับคีย์ไม่แตะเนื้อ
  คำที่เกินจำนวนห้องไปต่อท้ายห้องสุดท้าย เนื้อที่อยู่เหนือโน้ตบรรทัดแรกไม่แสดง แต่จัดระเบียบแล้วไม่หาย

**เก็บงาน**
- จำโน้ตและการตั้งค่าไว้ในเบราว์เซอร์อัตโนมัติ
- เซฟ/เปิดเป็นไฟล์ `.json` · บันทึกเสียงเป็น `.wav`

## เสียงขลุ่ย

หน้าขลุ่ยใช้ไฟล์เสียงที่อัดจากขลุ่ยจริง เลือกชุดให้เองตามชนิดคีย์

| ชุด | ใช้เมื่อ | ขั้น | ช่วง | ลักษณะ |
|---|---|---|---|---|
| ขลุ่ยเพียงออ | เลือกทางไทย | 12 | 459–1349 Hz | เสียงเท่า 7 เสียงจริง เพี้ยนไม่เกิน ±24¢ |
| ขลุ่ยคีย์ซี | เลือกคีย์สากล | 14 | 534–1999 Hz | บันไดเมเจอร์ ครบ 2 คู่แปด |

แต่ละไฟล์เก็บแค่หัวเสียงกับ loop หนึ่งรอบ ที่ crossfade ปลายให้ต่อกับต้น loop ไว้แล้ว
โน้ตยาววน loop โน้ตสั้นอย่างลูกสะบัดใช้แค่หัวเสียง
ทุกไฟล์ปรับความดังของตัวเสียงให้เท่ากัน ไม่ใช่ปรับตามยอดคลื่น จะได้ไม่มีเสียงไหนโผล่ออกมาจากพวก

เสียงอ้างอิงเริ่มต้นตั้งให้ `ด` ตกตรงเสียงต่ำสุดของขลุ่ยตัวนั้นพอดี ทุกทางจึงเข้าล็อกกับรูนิ้วจริง
โน้ตที่เกินช่วงที่อัดไว้ต้องยืดตัวอย่างขึ้นเท่าตัว ระบบลดระดับและกรองความสูงลงชดเชยให้ แต่ยังไม่เท่าของจริง

## ดนตรีคลอจาก MIDI

`backing.html` เปิดไฟล์ `.mid` / `.kar` แล้วเล่นเป็นดนตรีคลอให้เป่าขลุ่ยตาม อ่านไฟล์ในเครื่องล้วน
ลาก `.lyr` กับ `.cur` ของชุดคาราโอเกะ NCN มาพร้อมกันได้ จะได้ชื่อเพลง คีย์จากไฟล์ และเนื้อร้องวิ่งตาม

| เรื่อง | ทำอย่างไร |
|---|---|
| แยกแทร็ก | แยกตาม (แทร็ก × ช่อง) เพราะไฟล์ format 0 กับคาราโอเกะยัดทุกเครื่องไว้แทร็กเดียว อ่าน program และ CC7 แยกช่อง |
| ปิดทำนอง | ให้คะแนนแบบเดียวกับหน้าแกะโน้ต บวกช่อง 4 เล็กน้อยตามนิสัยไฟล์คาราโอเกะไทย แล้วปิดเสียงแทร็กที่ชนะ ติ๊กเปิดกลับหรือลดระดับเสียงให้เป็นทำนองนำเบา ๆ ได้ |
| เลื่อนคีย์ | เดาคีย์เพลงด้วย Krumhansl–Schmuckler จากแทร็กทำนอง แล้วเลื่อนให้ ด ตรงกับ ด ของขลุ่ยที่เลือก (เพียงออ = B♭ คีย์ซี = C หรือคีย์อื่น) เลือกทางที่เลื่อนน้อยที่สุดในช่วง −5..+6 มีช่องปรับเพิ่มเอง ±12 และจูนละเอียดเป็นเซนต์ |
| ความเร็ว | ตั้งเป็น % ของต้นฉบับ 40–150 เปลี่ยนกลางเพลงได้ เสียงไม่ต่ำลงเพราะเล่นจากโน้ตไม่ใช่จากไฟล์เสียง |
| วนช่วง | ตั้งจุดเริ่ม/จบจากตำแหน่งปัจจุบัน หรือกด 🔁 เฉย ๆ เพื่อวนทั้งเพลง |
| นับนำ | เคาะ 1 ห้องตามอัตราจังหวะของไฟล์ก่อนเข้าเพลง ปิดได้ |
| เนื้อร้อง NCN | `.lyr` เป็น TIS-620 (รับ UTF-8 ด้วย): บรรทัด 1 ชื่อเพลง 2 ศิลปิน 3 คีย์ 4 ว่าง ที่เหลือเนื้อร้อง — คีย์จากไฟล์ทับค่าที่เดา · `.cur` เป็น uint16 LE หนึ่งค่าต่อหนึ่งตัวอักษรรวมตัวขึ้นบรรทัด หน่วย 1/24 จังหวะ (tick = ค่า × ppq/24) ค่าที่เกินหรือขาดท้ายไฟล์ปล่อยผ่าน · คลิกบรรทัดกระโดด ปุ่ม ⟲ วนเฉพาะท่อน |

เสียงเป็นเครื่องสังเคราะห์แบบ GM ย่อ 12 ตระกูล (เปียโน ระฆัง ออร์แกน กีตาร์ เบส เครื่องสาย ทองเหลือง ลิ้น ขลุ่ย ซินธ์นำ ซินธ์คลอ ดีด)
กลองช่อง 10 สังเคราะห์แยกกระเดื่อง สแนร์ ไฮแฮต ทอม ฉาบ ไรด์ ไม่ใช่ซาวด์ฟอนต์จริง
ยังไม่อ่าน pitch bend และ sustain (CC64)

## แกะโน้ตจาก MIDI

`listen.html` อ่านไฟล์ `.mid` ในเครื่องล้วน ไม่มีการอัปโหลดไปไหน
รองรับ format 0 กับ 1 อ่าน running status และรวม tempo map จากทุกแทร็ก
— format 1 เก็บ tempo ไว้แทร็กเดียวแต่มีผลกับทุกแทร็ก ถ้าอ่านเฉพาะแทร็กทำนองจะเพี้ยนทั้งเพลง

**เดาให้ก่อน แล้วให้คนแก้**

| ขั้น | ทำอะไร |
|---|---|
| เลือกแทร็ก | ตัดช่อง 10 (กลอง) และแทร็กว่างทิ้ง ให้คะแนนจากเสียงเฉลี่ยสูง โน้ตไม่ซ้อนกัน และชื่อแทร็ก |
| หาคีย์ | Krumhansl–Schmuckler — เทียบ histogram ของเสียงกับโปรไฟล์เมเจอร์/ไมเนอร์ทั้ง 24 คีย์ |
| ความเร็ว | อ่านจาก tempo ตัวแรก แล้วเลือกจำนวนจังหวะต่อห้องให้ค่าอยู่ในช่วงที่หน้าเล่นรับได้ |
| ช่วงเสียง | เลือกให้เครื่องหมายคู่แปดน้อยที่สุด |

คีย์ไมเนอร์เขียนเป็นเมเจอร์คู่ขนาน เสียงหลักจะไปตกที่ `ล` ตามที่คนไทยแกะเพลงฝรั่งกัน
เพราะ `SEMI = [0,2,4,5,7,9,11]` ทำให้ `ด ร ม ฟ ซ ล ท` ตรงกับบันไดเมเจอร์พอดี
เพลงที่แปลงแล้วส่งไปหน้าเล่นจึงตั้งระบบเสียงเป็น **เทียบเปียโน (12-TET)** กับคีย์สากลให้อัตโนมัติ เสียงจะออกมาตรงคีย์เดิม

**ที่แปลงไม่ตรง** — หน้านี้นับให้ดูเสมอ

- **ตัวนอกบันไดเสียง** โน้ตไทยมี 7 ตัวต่อคู่แปด ไม่มีที่ให้ชาร์ปแฟลต ระบบปัดขึ้นหาตัวใกล้สุด
  (ปัดขึ้นเพราะตัวนอกบันไดเสียงในเพลงสากลส่วนใหญ่เป็นตัวที่ยกขึ้น และเส้นทำนองไม่แบนทั้งขาขึ้นและขาลง)
- **สามพยางค์ สวิง 3/4 6/8** ห้องไทยแบ่งได้แต่ 2 กับ 4 — ระบบเตือนตอนเปิดไฟล์
- **เปลี่ยนคีย์กลางเพลง** คิดคีย์เดียวทั้งเพลง ท่อนที่เปลี่ยนจะเพี้ยน
- **โน้ตชนกันในช่อง** ถ้าสถิติไม่เป็นศูนย์ แปลว่ากริดหยาบไป เพิ่มช่องต่อห้องหรือลดจังหวะต่อห้อง

ดึงเสียงจากไฟล์อัด (mp3 จาก YouTube ฯลฯ) ยังทำไม่ได้ — ดูหัวข้อถัดไป

## ยังไม่ได้ทำ

- **แกะจากไฟล์เสียง** ต้องมี pitch tracker (YIN) + onset detector + จับฉิ่งเพื่อหาเส้นแบ่งห้อง
  เดี่ยวขลุ่ย/ซอ/เสียงร้องพอไหว วงปี่พาทย์เต็มวงต้องใช้ ML model ทำในเบราว์เซอร์ล้วนไม่ได้
- **เครื่องมือช่วยแกะเอง** ชะลอความเร็วโดยเสียงไม่ต่ำลง วนซ้ำช่วงสั้น เดินทีละโน้ต
- **เสียงควงจริง** ตอนนี้ใช้การกรองให้ทึบลงจากไฟล์เดิม ไม่ใช่เสียงอัดจากการจับแบบควง
- **`ลํ` `ทํ` ของเพียงออ** ยังต้องยืดขึ้นคู่แปดจากตัวอย่างที่มี

## โครงไฟล์

```
index.html     หน้าแรก — หน้าเดียวจบ ไม่มีสคริปต์
thai.html      หน้าโน้ตไทย — แก้ไฟล์นี้โดยตรง เป็นต้นทาง
khlui.html     หน้าขลุ่ย — สร้างจาก thai.html อย่าแก้มือ
backing.html   หน้าดนตรีคลอ — ไฟล์อิสระ ใช้ MIDI parser ชุดเดียวกับ listen.html (คัดลอกมา ไม่ได้แชร์โค้ด)
listen.html    หน้าแกะโน้ต — ไฟล์อิสระ ไม่เกี่ยวกับสองหน้าข้างบน
               ตอนนี้ซ่อนจากเมนูไว้ จะเอากลับให้เติมแท็บใน nav ของ thai.html กับการ์ดใน index.html
tools/         สคริปต์สร้างและทดสอบ (ดู tools/README.md)
samples/       ไฟล์เสียงขลุ่ยที่สกัดแล้ว + ค่าความถี่และจุด loop
raw/           ไฟล์อัดต้นฉบับ
```

`khlui.html` ถูกสร้างขึ้นมา ถ้าจะแก้อะไรที่มีทั้งสองหน้าเล่นโน้ต ให้แก้ `thai.html` แล้วสร้างใหม่

```bash
python tools/make_khlui.py && python tools/build_sampler.py
node tools/smoke.js thai.html && node tools/smoke.js khlui.html
node tools/smoke_listen.js listen.html
node tools/smoke_backing.js backing.html
```
