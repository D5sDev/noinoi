# tools

สคริปต์สร้าง `khlui.html` และทดสอบทั้งสองหน้า
ต้องมี `python` (numpy, scipy), `node` และ `ffmpeg`

## ไปป์ไลน์

```
index.html ──make_khlui.py──▶ khlui.html (โครง) ──build_sampler.py──▶ khlui.html (ครบ)
                                                        ▲
raw/*.mp3 ──extract_*.py──▶ samples/*.wav + *_meta.json ┘
```

`index.html` เป็นต้นทางที่แก้ด้วยมือ ส่วน `khlui.html` สร้างขึ้นมาทั้งหมด **อย่าแก้มือ**

## สั่งงาน

```bash
# สร้าง khlui.html ใหม่จาก index.html (ทำทุกครั้งที่แก้ index.html)
python tools/make_khlui.py && python tools/build_sampler.py

# ทดสอบ
node tools/smoke.js index.html && node tools/smoke.js khlui.html

# สกัดตัวอย่างเสียงใหม่จากไฟล์อัด (ทำเมื่อเปลี่ยนไฟล์ใน raw/ เท่านั้น)
python tools/extract_phiangor.py
python tools/extract_ckey.py
```

## แต่ละไฟล์ทำอะไร

| ไฟล์ | หน้าที่ |
|---|---|
| `make_khlui.py` | คัด `index.html` เป็นหน้าขลุ่ย — ตัดช่องเลือกเครื่องดนตรี เพิ่มลูกสะบัด/เสียงควง เปลี่ยนตัวอย่างโน้ตและคำอธิบาย |
| `build_sampler.py` | ฝังไฟล์เสียงจาก `samples/` เป็น base64 และเปลี่ยน `playTone` ให้ใช้ sampler |
| `extract_phiangor.py` | ตัดเสียงเพียงออ 12 ขั้นจาก `raw/เพียงออ.mp3` (ล่าง 7 จับนิ้ว + บน 5 เป่าทบ) |
| `extract_ckey.py` | ตัดเสียงคีย์ซี 14 ขั้นจากไฟล์อัด 3 ไฟล์ |
| `samplenorm.py` | ปรับความดังของตัวเสียงให้เท่ากันทุกไฟล์ แล้วกดเฉพาะหัวเสียงที่โด่งเกิน |
| `smoke.js` | รันสคริปต์ในไฟล์จริงบน DOM + Web Audio จำลอง แล้วกดปุ่มทุกปุ่ม |

## การสกัดตัวอย่างเสียงทำอะไรบ้าง

1. หาช่วงที่มีเสียงยาวพอ ตัดหัวท้ายให้ชิด
2. วัดความถี่ด้วยสเปกตรัมคูณฮาร์มอนิก แล้วละเอียดด้วย autocorrelation — กันอ่านผิดไปคนละคู่แปด
3. หาช่วง loop ที่คลื่นก่อนต้น loop กับก่อนปลาย loop เหมือนกันที่สุด (เวกเตอร์ทั้งแถบด้วย FFT)
4. crossfade ปลาย loop ให้ต่อกับต้น loop — วนแล้วต่อเนื่องพอดีโดยไม่มีเสียงกึก
5. ปรับความดัง แล้วลดอัตราสุ่มเหลือ 22.05 kHz
6. เก็บแค่ **หัวเสียง + loop หนึ่งรอบ** ปลายไฟล์คือปลาย loop จึงไม่ต้องเก็บค่า `loopEnd`

`*_meta.json` เก็บชื่อไฟล์ ความถี่ที่วัดได้ และตำแหน่งเริ่ม loop

## smoke.js ตรวจอะไร

ไม่ได้ตรวจแค่ syntax — โหลดสคริปต์จริงเข้าไปรันบน DOM กับ Web Audio ที่จำลองขึ้น
โดย `querySelector` คืน `null` ให้ id ที่ไม่มีจริงเหมือนเบราว์เซอร์ แล้วกดปุ่มทีละปุ่ม

ตรวจว่า: โหลดผ่าน · กดเล่นแล้วมีเสียงถูกตั้งคิว · จัดระเบียบโน้ต · เซฟแล้วเปิดกลับได้ค่าเดิม ·
จำลง localStorage · สลับคีย์สากลแล้วเสียงอ้างอิงเปลี่ยนตาม · ขยับคีย์โน้ตขึ้นแล้วลงได้เดิมคืน ·
ตั้งจุดเริ่มเล่น · พัก/เล่นต่อ · หยุด

พร้อมทั้งจับค่าเวลาที่เป็น NaN, `exponentialRamp` ที่รับค่าติดลบ และ `alert` ที่ไม่ควรเด้ง
